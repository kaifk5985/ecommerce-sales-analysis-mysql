# E-Commerce Sales Analysis Using MySQL

## Project Overview
This project analyzes e-commerce sales data using MySQL to understand sales performance, customer purchasing behavior, product performance, and order status.

## Tools Used
- MySQL
- MySQL Workbench
- SQL

## Database Tables
- customers
- products
- orders
- order_items

## Key Analysis
- Monthly revenue analysis
- Top customers by spending
- Product sales and revenue analysis
- Order status analysis
- Customer segmentation
- Data quality checks

## SQL Concepts Used
- SELECT, WHERE, ORDER BY
- GROUP BY and HAVING
- Aggregate functions
- INNER JOIN and LEFT JOIN
- Subqueries and CTEs
- CASE WHEN
- Window functions
- Data quality validation

## Project Structure
- `01_database_setup.sql` — Creates the database and tables.
- `02_data_analysis.sql` — Contains SQL queries for business analysis.
- `03_sample_data.sql` — Contains sample data for the project.

## Objective
The objective is to use SQL to transform e-commerce data into meaningful business insights about revenue, customers, products, and orders.
